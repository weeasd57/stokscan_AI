# SideProjectors Step 6 Inputs

Here are the recommended inputs for Step 6 on SideProjectors:

---

### 1. What items are included in the sale?
Check the following boxes:
- [x] **Domain name**
- [x] **Source code**
- [x] **All related data**
- [x] **Design, images, logo**

### 2. Are there anything else that you want to include as part of this sale?
`Deployment configuration guides (Vercel, Supabase, Hugging Face) and full database schema configurations.`

### 3. How much are you selling this project for?
* Enter: **`10000`** (or `10000.00`)
* Select the radio button: **"Above price is a guideline & is negotiable, so please contact me."**

### 4. Why are you selling this project?
`Focusing on new developer tools and side projects. I do not have the marketing/growth time required to promote and scale this localized stock-trading platform to its full potential.`

### 5. How can the buyer take this project further?
`Introduce paid subscriptions ($10-$25/mo) for the Telegram bot alerts, integrate local Egyptian payment gateways (e.g. Paymob, Fawry), promote the platform in local stock trading communities (Facebook, Twitter, Telegram), and expand coverage to include crypto, forex, or regional Gulf exchanges (Tadawul).`
