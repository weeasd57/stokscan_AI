### Startup Description (~830 characters)

EGX Bots is a fully automated, AI-powered stock scanner and trading signal platform designed specifically for the Egyptian Stock Exchange (EGX). Using machine learning models (LightGBM/Optuna) and advanced quantitative metrics, the platform scans the entire market daily to generate high-probability buy/sell signals, track user portfolios in real-time, and deliver instant exit alerts via Telegram.

With a serverless architecture designed for zero maintenance, the entire system runs on free tiers (Vercel, Supabase, Hugging Face) resulting in virtually $0/month in operating costs. It features automated daily price sync, technical indicator calculation, sentiment-analyzed financial news, and a KNN-based chart similarity search. Highly scalable and subscription-ready, it is built to empower retail traders with institutional-grade tools in a rapidly growing market.
