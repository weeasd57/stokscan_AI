================================================================================
ARCHITECTURE OVERVIEW
================================================================================

Layer 1: Intent Parser (parse_user_intent)
   - Extracts intent WITHOUT analyzing stocks
   - Maps Arabic company names to symbols
   - Extracts tickers, entry prices, and criteria
   - NO LLM hallucination possible at this stage

Layer 2: Tool Executor (ChatbotTools)
   - Retrieves data from Supabase ONLY
   - No decision-making, pure data retrieval
   - Returns structured results

Layer 3: Response Generator
   - Uses Analysis Engine for scoring
   - Template-based responses
   - NO invention, only data-driven answers

Layer 4: Validator (chatbot_validator.py)
   - Checks responses for hallucinations
   - Validates all claims against database
